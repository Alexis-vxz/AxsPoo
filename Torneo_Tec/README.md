# 🎮 Torneo de Videojuegos 

Este proyecto es un programa en Python que simula la gestión de usuarios en un sistema de competencias, donde existen dos tipos principales de usuarios:

- 🏆 Competidores
- 👀 Observadores

Cada tipo de usuario tiene diferentes funcionalidades como ganar o perder puntos, así como registrar o eliminar observaciones.

---

## 📌 Características

### 🏆 Competidor
- Crear un perfil con nombre, ID, nivel, puntos y equipo
- Ganar puntos
- Perder puntos
- Mostrar información del perfil

### 👀 Observador
- Crear un perfil con nombre, ID, nivel, puntos y lista de observaciones
- Ver partidas (agregar observaciones)
- Eliminar observaciones
- Mostrar información del perfil

---

## 🛠️ Tecnologías utilizadas
